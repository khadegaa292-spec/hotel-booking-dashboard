# 🏨 Hotel Booking Analysis

An end-to-end analysis of 86,000+ hotel bookings (July 2015 – August 2017) across a City Hotel and a Resort Hotel. The project explores booking behavior, cancellations, and revenue performance, and presents the findings through dashboards built in four different tools.

## 📊 Key Findings

| Metric | Value |

| Total Bookings | 86,639 |
| Cancellation Rate | 27.68% |
| Realized Revenue | $6.46M |
| Revenue Lost to Cancellations | $2.83M |
| Average Daily Rate (ADR) | $107.24 |
| Average Stay | 3.65 nights |

## 🎯 Objectives

- Identify booking patterns across hotel types, markets, and customer segments
- Analyze cancellation drivers (deposit type, lead time, market segment)
- Measure revenue performance and revenue lost to cancellations
- Compare how each BI tool presents the same business questions
